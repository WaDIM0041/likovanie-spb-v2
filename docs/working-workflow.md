# Порядок работы с сайтом V2

Согласовано с владельцем 20.10.2026.

## Разработка и проверка

Рабочий репозиторий: [WaDIM0041/likovanie-spb-v2](https://github.com/WaDIM0041/likovanie-spb-v2).

Основной адрес для просмотра правок: [GitHub Pages V2](https://wadim0041.github.io/likovanie-spb-v2/). Главная страница собирается из корневого `index.html`. Репозиторий `likovanie-spb` относится к предыдущей версии.

Все последующие правки сначала вносить в V2, проверять локально, сохранять в GitHub и проверять фактическую публикацию GitHub Pages. Визуальные изменения смотреть на компьютерных и мобильных ширинах; проверять затронутые кнопки, анимации, загрузку ресурсов и горизонтальное переполнение. Выбирать проверки по изменению, не запускать все тесты повторно для каждого изменения документации.

После изменения CSS/JS/SVG обновлять версии статических ресурсов через `node scripts/version-static-assets.cjs`. При изменении исходников motion предварительно пересобирать соответствующие bundles. Перед началом получать новые изменения из GitHub и сохранять работу, выполненную владельцем из другого места.

Успешный push не равен успешной публикации: подтвердить завершение GitHub Pages и доступность обновлённой страницы. В итоговом сообщении давать ссылку на GitHub Pages с версией для проверки.

## Перенос проверенного выпуска на хостинг

Хостинг `http://likovanie.annakam.ru/` обновляется отдельно. Владелец загружает подготовленные файлы самостоятельно. Автоматическую FTP-загрузку выполнять только по отдельному прямому запросу.

Для небольшого выпуска готовить папку `update_ГГГГ-ММ-ДД_ЧЧ-ММ` с изменёнными файлами и сохранёнными относительными путями. Время московское, UTC+3, фактическое время подготовки. ZIP с тем же именем допустим дополнительно; упаковка не обязательна. Полный комплект при необходимости называть `site_full_ГГГГ-ММ-ДД_ЧЧ-ММ`. Не добавлять хеши в пользовательские имена выпусков, версии кода и базы записывать в инструкции.

Выдавать прямую ссылку на папку, список файлов и инструкцию: резервная копия, перенос содержимого в `/www/likovanie.annakam.ru/`, объединение существующих папок, замена совпадающих файлов, `index.html` последним. Остальные файлы сайта сохранять.

Подтверждённая версия хостинга на 20.10.2026: `fe6f8cf`, ручная загрузка владельцем проверена по HTTP и в Chrome. Текстовые файлы совпадают с исходником после нормализации CRLF/LF, изображения совпадают побайтно. Это база для следующего обновления хостинга. После сообщения владельца о новой загрузке проверять опубликованные файлы и обновлять запись о базе.

В отчёте различать подготовку файлов, публикацию GitHub Pages и фактическую проверку хостинга. Основной домен школы `likovanie-spb.ru` пока не переключён.
